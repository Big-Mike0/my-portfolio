# Developer Portfolio

A modern, responsive developer portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 How to Run

1.  **Open the project folder**:
    The code is located at:  
    `c:\Users\DELL XPS\.gemini\antigravity\scratch\developer-portfolio`

2.  **Install dependencies** (first time only):
    ```bash
    npm install
    ```

3.  **Start the development server**:
    ```bash
    npm run dev
    ```
    Open your browser to `http://localhost:5173`.

## 🛠️ Customization

-   **Personal Info**: Edit `src/components/Hero.tsx`, `Navbar.tsx`, and `Footer.tsx`.
-   **Projects**: Add your projects in `src/components/Projects.tsx`.
-   **Skills**: Update your skills in `src/components/Skills.tsx`.
-   **CV**: Place your `resume.pdf` in the `public/` folder.
-   **Email Contact**: Configure your EmailJS keys in `src/components/Contact.tsx`.

## 📦 Build for Production

To create a production-ready build:
```bash
npm run build
```
The output will be in the `dist/` folder.
